### 🛡️ Featured project — [malscan](https://github.com/Kartik0219/malscan)

A local, on-demand **malware scanner** with a multi-layer detection stack — the
project I use to learn how real antivirus works, end to end.

- **8 detection engines:** hash blocklist · entropy/PE heuristics · file-type
  masquerading · ClamAV-style logical signatures · YARA · a trainable **ML
  classifier** · a local **reputation cache** · VirusTotal
- **Real-time folder monitoring**, a reversible **quarantine vault**, and
  **AI-assisted triage** that explains findings in plain English
- Reports in JSON / HTML / **SARIF** (uploads to GitHub code scanning)
- 130+ automated tests · downloadable Windows & macOS builds ·
  [live demo](https://malscan.onrender.com)
